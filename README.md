# Smart Vision Toolkit

A Python + OpenCV computer vision project for basic image preprocessing, edge detection,
thresholding, contour extraction, and simple object analysis.

## Features
1. Synthetic sample image generation
2. Grayscale conversion
3. Gaussian blur
4. Canny edge detection
5. Binary thresholding
6. Contour detection and bounding boxes
7. Image statistics
8. Output visualization
9. Automated test cases

## Requirements
- Python 3.9+
- OpenCV
- NumPy

Install:
```bash
pip install -r requirements.txt
```

## Run
Generate outputs:
```bash
python main.py
```

Run the test suite:
```bash
python tests/test_vision_toolkit.py
```

The project intentionally uses a generated sample image so that the demo is reproducible
without downloading an external dataset.
